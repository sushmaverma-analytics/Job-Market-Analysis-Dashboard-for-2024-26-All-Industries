# Job-Market-Analysis-Dashboard-for-2024-26-All-Industries
Job Market Analysis Dashboard for 2024-26: All Industries
## Project Overview
- This Power BI dashboard analyzes job market trends for 2024-26 across all industries by examining Total Job, Job title, job type , Skills required, work mode, Salary LPA,Education required, Experience category and company rating, Salary patterns, applicant competition. The goal is to help job seekers and recruiters make data-driven decesions.

## Data Source:
- CSV flat file.

## Records: 
- 23K + Job Postings.
- 
## Domain:
Recruitment/ Job Market Analytics.

## Period:
- 2024-26
## Tools Used:
- Power Query,
- Power BI Desktop
- DAX
- Data Visualization
## Data Cleaning (ETL):
- Performed in Power Query Editor:
- Removed duplicate, Removed blank cells, Replaced Null values, Cleaned text values, Trimed, Removedn Errors, Changed Data Type, Capitalization of Required words,
- split skills column into rows by delimeter, Created experience categories, Handled inconsistent values, Built analytical structure for reporting.
## Data Modeling: 
- created one fact table (Job_Market and additional dimension tables to create one to many cardinality, a star Schema approach was used to improve performance and simplify analysis.

## DAX Measures:

- Dynamic Dashbord title
